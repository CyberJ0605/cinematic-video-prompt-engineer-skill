# Cinematic Video Prompt Engineer Skill

> 电影感视频提示词工程师：把剧情、小说片段和场景想法，转成可直接用于 AI 视频生成的电影感提示词。

![version](https://img.shields.io/badge/version-v1.5.0-blue)
![license](https://img.shields.io/badge/license-MIT-green)
![platform](https://img.shields.io/badge/platform-Codex%20Skill-black)

它用于把剧情梗概、人物关系、场景设定、小说片段和情绪方向，改写成适合 Kling、Seedance、Veo、Sora、Runway、即梦等 AI 视频模型生成的电影感视频提示词。它不是简单堆叠镜头术语，而是先判断剧情能否在 6-30 秒内自然呈现，再把心理动机、表演节拍、台词、动作、空间、光影和声音组织成可执行的生成方案。

## 快速开始

1. 安装 `cinematic-video-prompt-engineer` skill。
2. 在 Codex 输入：`请用 $cinematic-video-prompt-engineer 处理这个剧情：...`
3. 普通剧情会进入打磨模式；高歧义、长剧情或敏感风格边界会先进入方向确认模式。
4. 可选：先用【建议先生成的参考图】生成角色、场景或关键道具。
5. 复制【最终视频提示词】到 AI 视频模型生成视频。

## 当前版本重点

- 30 秒复杂表演：支持韩语等原生同步对白、密集台词、抢话、打断、短暂重叠、画外音和未完成句，同时保护说话者身份、口型、声线与反应时机。
- 活人感与表演动机：让眼神、表情、呼吸、停顿、语气、手部动作、身体重心和环境反馈共同服务于人物当下目的。
- 认知与证据控制：区分观众知道什么、角色知道什么、角色何时获得证据，避免人物提前反应或镜头重复解释。
- 连续性与行为回收：维护人物、声线、场景、道具、轴线和情绪余波，并用动作习惯、关系边界或关键物件完成结尾回收。
- 6-30 秒自适应：根据可播放内容选择时长，不硬凑 30 秒；最终提示词采用分时长目标区间和绝对上限。

## 能力一览

| 能力 | 说明 |
|---|---|
| 剧情诊断 | 先判断情绪核心、视觉核心、结构和时长，不直接堆镜头词。 |
| 电影化改写 | 把抽象剧情转成可见动作、表演、光影、声音和镜头调度。 |
| 四种输出模式 | 支持精简模式、打磨模式、方向确认模式和连续短片模式。 |
| 参考图提示词 | 给出人物、场景、关键道具或双人关系图提示词，提升视频稳定性。 |
| 6-30 秒视频提示词 | 根据剧情判断实际时长，输出可直接复制到视频模型的最终提示词，不硬凑 30 秒。 |
| 密集对白表演 | 支持原生对白、抢话、打断、重叠、停顿、呼吸、画外音、听者反应和声线连续性。 |
| 活人感控制 | 统一心理动机、微表情、伴随动作、人体联动、物理接触、环境响应和拍摄条件。 |
| 认知与证据控制 | 管理角色知识状态、观众信息差、反应时机、证据经济和悬念揭示。 |
| 长剧情拆分 | 当剧情超过 30 秒承载能力或提示词超出时长对应字数预算时，建议拆分并说明本段呈现内容。 |
| 续写能力 | 支持从上一段故事状态继续，保持人物、场景、道具和情绪连续。 |
| 小说片段改编 | 支持小说/长文本的片段筛选、外化改写和连续短片结构。 |
| 专项场景 | 支持微表情、多人对话、悬疑、群像、大场面压缩、非人类角色、灯光设计和近身打斗。 |

## 适合用于

- 6-30 秒 AI 视频片段
- 情绪戏、亲密张力、悬疑、家庭冲突、回忆蒙太奇
- 原生同步对白、多人抢话、都市婚姻争吵和长台词情绪递进
- 人物头部特写和微表情表现
- 产品 / 人物质感短片
- 群像和大场面的短视频压缩
- 长剧情拆分成多条连续提示词
- 小说片段、长文本剧情的电影化场景筛选与短视频改编
- 用户满意第一条后继续生成下一条视频提示词

## 不适合直接用于

- 完整长片剧本
- 小说润色、标题、口播稿
- 一次性生成超过 30 秒的复杂剧情
- 缺少人物、场景、情绪目标的空泛需求
- 高复杂度武术动作设计，仍建议提供动作参考样本
- 依赖大量屏幕文字、字幕、UI 内容才能理解的画面
- 露骨性内容、未成年人性化、非自愿性内容、过度血腥内容

### v1.5.0 - 30秒复杂表演与叙事连续性（2026-08-29）

- 单条提示词最长支持 30 秒，并按时长设置长度预算：1-15 秒上限 2000 字符、16-24 秒上限 3200 字符、25-30 秒上限 4000 字符；3000 字符以上只保留能提高生成稳定性的内容。
- 新增场景级表演契约、声线身份与临时声音状态、抢话/重叠对白、保护性口误和对白可播放性审计；密集对白不再按固定字数机械删减。
- 新增角色认知与证据控制、行为伏笔回收、主观声音透视、非人类角色表演、非对称身体构图、前景遮挡转场和背景自主运动。
- 强化短剧钩子诊断：异常事件、即时目标、规则代价、现实阻力、信息反转和未完成答案作为可选功能使用，不把所有剧情强行改成公式。

### v1.4.3 - 台词剪辑与声音光影控制（2026-08-03）

- 新增复杂对话的二级表演时间码、说话者/听者双表演轨、跨镜画外音与 `J-cut/L-cut` 声音桥，并让剪辑点跟随关键词、语义转折和声音破裂。
- 新增景别随心理防线递进规则：防御阶段保留 MCU/CU，真实情绪暴露时再进入 BCU/ECU。
- 建立声音与光影最低描述标准：每条提示词包含可信光源和具体声场，多镜头、悬疑、动作、续写等场景可用“整体声音与光影”统一连续性。

### v1.4.2 - 输出节奏与方向确认模式（2026-08-02）

- 明确默认输出为完整打磨模式：剧情诊断、电影化改写策略、建议参考图和最终视频提示词一起给出。
- 收紧精简模式触发条件：只有用户明确要求“直接给提示词”“不要分析”“只输出最终提示词”等，才只输出最终提示词。
- 新增方向确认模式：长剧情、高歧义、敏感风格边界或用户要求先讨论时，先输出诊断、策略和确认点，用户确认后再给参考图和最终视频提示词。

## 安装

### Codex 用户

把仓库里的 `cinematic-video-prompt-engineer` 文件夹复制到你的 Codex skills 目录。

如果你会使用 Git，可以克隆仓库：

```powershell
git clone https://github.com/CyberJ0605/cinematic-video-prompt-engineer-skill.git
```

如果不使用 Git，也可以在 GitHub 页面点击 `Code -> Download ZIP`，解压后复制其中的 `cinematic-video-prompt-engineer` 文件夹。

Windows 默认安装路径：

```powershell
C:\Users\你的用户名\.codex\skills\cinematic-video-prompt-engineer
```

如果你已把 skills 目录迁移到其他位置，例如：

```powershell
D:\Codex\skills
```

则放到：

```powershell
D:\Codex\skills\cinematic-video-prompt-engineer
```

安装后的结构应为：

```text
cinematic-video-prompt-engineer/
  SKILL.md
  agents/
    openai.yaml
  references/
    style_patterns.md
    evaluation_cases.md
```

不要出现同名嵌套目录：

```text
cinematic-video-prompt-engineer/cinematic-video-prompt-engineer/
```

### 非 Codex 用户

Claude、ChatGPT、DeepSeek、Kimi、通义、豆包等工具一般不能直接安装 Codex skill，但可以使用通用提示词版本。

复制 `PROMPT_VERSION.md` 中的全部内容给对应 AI，然后让它按规则扮演“电影感视频提示词工程师”即可。

## 使用

在 Codex 中调用：

```text
$cinematic-video-prompt-engineer
```

示例：

```text
请用 $cinematic-video-prompt-engineer 处理这个剧情：
深夜医院走廊，男人收到母亲抢救失败的消息，却因为年幼女儿在身边，只能蹲下给她系鞋带，把眼泪憋回去。
```

## 输出内容

默认输出：

```text
【剧情诊断】
【电影化改写策略】
【建议先生成的参考图】
【最终视频提示词】
```

如果用户只想要最终提示词，可以明确说“只给最终提示词”。

高歧义、长剧情、敏感边界或需要先讨论的请求，会先输出：

```text
【剧情诊断】
【电影化改写策略】
【需要你确认的方向】
```

用户确认方向后，再继续生成参考图和最终视频提示词。

最终视频提示词长度按视频时长控制，诊断、策略和参考图提示词不计入：

| 视频时长 | 推荐目标 | 绝对上限 |
|---|---:|---:|
| 1-15 秒 | 简单 500-800；常规 800-1300；复杂 1300-2000 字符 | 2000 字符 |
| 16-24 秒 | 1600-2600 字符 | 3200 字符 |
| 25-30 秒 | 2200-3400 字符 | 4000 字符 |

上限不是目标长度。超过 3000 字符的 25-30 秒提示词，每一段额外描述都应直接服务于表演、声音、空间连续性、动作可读性或失败预防。

基础概括：这是一段 15 秒低照度现实主义悬疑连续剪辑。深夜独居女孩回家，在玄关鞋柜上发现一把陌生钥匙，她试图说服自己只是记错；走进客厅后，卧室里传来很轻的手机震动声，她终于意识到家里可能有人。全片不出现怪物，不突脸，恐惧来自空间和声音。
