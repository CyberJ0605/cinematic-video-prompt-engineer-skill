# Cinematic Video Prompt Engineer Skill

> 电影感视频提示词工程师：把剧情、小说片段和场景想法，转成可直接用于 AI 视频生成的电影感提示词。

![version](https://img.shields.io/badge/version-v0.8.0-blue)
![license](https://img.shields.io/badge/license-MIT-green)
![platform](https://img.shields.io/badge/platform-Codex%20Skill-black)

它用于把剧情梗概、人物关系、场景设定、小说片段和情绪方向，改写成适合 Kling、Seedance、Veo、Sora、Runway、即梦等 AI 视频模型生成的电影感视频提示词。默认采用“打磨模式”：先诊断剧情，再给出电影化改写策略、可选参考图提示词，最后输出可复制的视频提示词。

## 快速开始

1. 安装 `cinematic-video-prompt-engineer` skill。
2. 在 Codex 输入：`请用 $cinematic-video-prompt-engineer 处理这个剧情：...`
3. 查看【剧情诊断】和【电影化改写策略】，确认理解方向。
4. 可选：先用【建议先生成的参考图】生成角色、场景或关键道具。
5. 复制【最终视频提示词】到 AI 视频模型生成视频。

## 当前版本重点

- 续写桥接：从上一段故事状态延续，不机械复刻尾帧。
- 参考图控制：单人参考图只生成一个人物，双人关系另用 two-shot reference。
- 小说片段改编：先筛选可电影化片段，再生成 15 秒内视频提示词。
- 电影化细节：支持镜头术语、光线设计、微表情、动作戏和声音设计。

## 能力一览

| 能力 | 说明 |
|---|---|
| 剧情诊断 | 先判断情绪核心、视觉核心、结构和时长，不直接堆镜头词。 |
| 电影化改写 | 把抽象剧情转成可见动作、表演、光影、声音和镜头调度。 |
| 参考图提示词 | 给出人物、场景、关键道具或双人关系图提示词，提升视频稳定性。 |
| 15 秒视频提示词 | 输出可直接复制到视频模型的最终提示词，默认控制在合理长度内。 |
| 长剧情拆分 | 当剧情超过 15 秒承载能力时，建议拆分并说明本段呈现内容。 |
| 续写能力 | 支持从上一段故事状态继续，保持人物、场景、道具和情绪连续。 |
| 小说片段改编 | 支持小说/长文本的片段筛选、外化改写和连续短片结构。 |
| 专项风格 | 支持微表情、多人对话、悬疑、群像、大场面压缩、灯光设计和近身打斗。 |

## 适合用于

- 8-15 秒 AI 视频片段
- 情绪戏、亲密张力、悬疑、家庭冲突、回忆蒙太奇
- 人物头部特写和微表情表现
- 产品 / 人物质感短片
- 群像和大场面的 15 秒压缩
- 长剧情拆分成多条 15 秒提示词
- 小说片段、长文本剧情的电影化场景筛选与短视频改编
- 用户满意第一条后继续生成下一条视频提示词

## 不适合直接用于

- 完整长片剧本
- 小说润色、标题、口播稿
- 一次性生成超过 15 秒的复杂剧情
- 缺少人物、场景、情绪目标的空泛需求
- 高复杂度武术动作设计，仍建议提供动作参考样本
- 依赖大量屏幕文字、字幕、UI 内容才能理解的画面
- 露骨性内容、未成年人性化、非自愿性内容、过度血腥内容

## 更新日志

本部分仅保留最近三次更新内容。

### v0.9.0 - 执行门槛与失败恢复（2026-06-26）

- 新增执行门槛表：遇到主角、地点、情绪转折缺失时先追问；遇到超 15 秒、台词过长、提示词超 2000 字或连续性不稳时先压缩、拆分或重建锚点。
- 新增长文本改编检查点：3000 字以上完整改编需先确认“片段拆选”或“连续短片结构”，避免直接生成失控的长提示词。
- 新增反模式红线：禁止逐句改编小说、堆砌镜头/灯光术语、隐藏关键台词、重置人物状态、把多人关系塞进单人参考图。
- 强化当前 skill 真源同步：发布包、源目录和本机安装版保持一致。

### v0.8.0 - 续写桥接与参考图控制（2026-06-23）

- 优化连续短片续写逻辑：从上一段故事状态延续，不再默认把上一段尾帧机械当作下一段首帧，可选择不同景别/角度、match-on-action 或完整新镜头组作为桥接。
- 强化参考图生成标准：人物、场景、道具参考图必须足够具体，可直接用于生产控制，并匹配当前段落的服装、妆发、损伤、湿尘、情绪基线、空间和光线状态。
- 新增单人参考图隔离规则：单人参考只描述一个可见人物，不把亲人、恋人、敌人、牵手、拥抱、保护、打斗等关系动作写进单人图，避免生成多余人物。
- 完善续写时参考图更新策略：角色、场景、道具无可见变化时沿用旧参考；出现新人、新地点、换装、新伤痕、新道具或状态变化时才补充新参考图。

### v0.7.0 - 镜头术语、灯光设计与近身打斗（2026-06-19）

- 新增按可播放画面内容判断时长的规则，不再只看文字长短；多事件、多台词、多动作或多情绪转折的短描述也会建议拆分。
- 统一分镜提示词中的专业镜头术语，补充 `ECU`、`VCU`、`BCU`、`CU`、`MCU`、`WS`、`KS`、`FLS`、`LS`、`ELS` 及 `Dolly In/Out`、`Pan`、`Tilt`、`Track`、`Zoom` 等运镜写法。
- 新增电影灯光设计规则，强调光源动机、光线触碰的具体表面、动态光影互动、低调高反差结构与不同光色的叙事功能。
- 新增港片犯罪长镜头近身打斗模板，强化一镜到底、全身可读性、环境撞击反馈、接触点、重心、声音和安全约束。

## 安装

### Codex 用户

把仓库里的 `cinematic-video-prompt-engineer` 文件夹复制到你的 Codex skills 目录。

如果你会使用 Git，可以克隆仓库：

```powershell
git clone https://github.com/CyberJ0605/cinematic-video-prompt-engineer-skill.git
```

如果不使用 Git，也可以在 GitHub 页面点击 `Code -> Download ZIP`，解压后复制其中的 `cinematic-video-prompt-engineer` 文件夹。

Windows 默认安装路径：

```powershell
C:\Users\你的用户名\.codex\skills\cinematic-video-prompt-engineer
```

如果你已把 skills 目录迁移到其他位置，例如：

```powershell
D:\Codex\skills
```

则放到：

```powershell
D:\Codex\skills\cinematic-video-prompt-engineer
```

安装后的结构应为：

```text
cinematic-video-prompt-engineer/
  SKILL.md
  agents/
    openai.yaml
  references/
    style_patterns.md
    evaluation_cases.md
```

不要出现同名嵌套目录：

```text
cinematic-video-prompt-engineer/cinematic-video-prompt-engineer/
```

### 非 Codex 用户

Claude、ChatGPT、DeepSeek、Kimi、通义、豆包等工具一般不能直接安装 Codex skill，但可以使用通用提示词版本。

复制 `PROMPT_VERSION.md` 中的全部内容给对应 AI，然后让它按规则扮演“电影感视频提示词工程师”即可。

## 使用

在 Codex 中调用：

```text
$cinematic-video-prompt-engineer
```

示例：

```text
请用 $cinematic-video-prompt-engineer 处理这个剧情：
深夜医院走廊，男人收到母亲抢救失败的消息，却因为年幼女儿在身边，只能蹲下给她系鞋带，把眼泪憋回去。
```

## 输出内容

默认输出：

```text
【剧情诊断】
【电影化改写策略】
【建议先生成的参考图】
【最终视频提示词】
```

如果用户只想要最终提示词，可以明确说“只给最终提示词”。

### 案例 2：悬疑，独居女孩发现陌生钥匙

视觉核心：除夕饭桌、红色灯笼光、热气腾腾的菜、母亲夹菜回避、女儿停筷、父亲稳定宣布。
结构判断：适合 15 秒饭桌多人对话连续剪辑，需要切换三人反应，不适合单一长镜头。
时长判断：15 秒内只呈现宣布、追问、父亲解释、女儿意识到四个核心节点，不展开争吵。
取舍与补全：补入父亲和女儿关键台词，母亲用动作和沉默表达立场；结尾留给冷掉的饭桌气氛。

【电影化改写策略】
用饭桌中心构图和交叉特写表现权力关系：父亲坐主位，母亲在侧面回避，女儿在对面被迫接收决定。声音从热闹电视春晚逐渐被压低，只留下筷子碰碗声和沉默。
